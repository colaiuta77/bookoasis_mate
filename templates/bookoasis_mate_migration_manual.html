카테고리 이관 매뉴얼

.oasis.zip은 DB 엔진과 무관한 데이터 패키지입니다. SQLite↔MariaDB로 옮길 수 있으며, 통DB 복원과 달리 카테고리 단위로 추가·병합합니다.

패키지대상포함 정보
도서일반·성인도서·진행률·표지·오프셋 정보.
오디오북오디오북오디오북·트랙·재생 진행률·포스터.
비디오비디오비디오·에피소드·재생 진행률·포스터.

원본 도서·음원·영상 파일은 포함하지 않습니다. 미디어 파일을 별도로 준비하고 대상 경로를 맞추세요. 카테고리 이관에는 별도 Dry Run이 없습니다.

내보내기

  1. 복사 설정에서 이관 작업 디렉터리와 내보내기를 선택합니다.
  2. DB와 카테고리를 선택해 저장합니다.
  3. 복사 상태 → 시작을 누릅니다. 결과의 패키지 경로를 확인합니다.

신규 카테고리로 가져오기

  1. 패키지를 이관 작업 디렉터리에 복사하고 가져오기에서 선택합니다.
  2. 패키지 검사로 유형·포함 정보·원본 경로를 확인합니다.
  3. 대상 DB와 신규 카테고리를 선택하고 대상 물리 경로를 한 줄씩 입력합니다.
  4. DB 백업을 켜고 저장한 뒤 복사 상태에서 시작합니다.

기존 카테고리에 병합

가져오기 방식을 기존 카테고리 병합으로 바꾸고 대상 DB·카테고리를 선택합니다. 기존 경로는 유지하고 새 경로를 추가하며, 최종 경로가 중복되는 항목은 건너뜁니다.

경로·백업 주의사항

  • 대상 경로는 원본 루트 순서대로 대응합니다. 개수가 부족하면 남은 루트는 첫 대상 경로를 사용하므로 검사 결과를 확인하세요.
  • 대상 물리 경로는 BookOasis가 사용할 절대 경로입니다. 가져오기 과정에서 FF도 디렉터리를 생성하므로 접근 권한이 필요합니다.
  • 가상 그룹은 이관하지 않습니다. 가져오기 후 BookOasis에서 다시 지정합니다.
  • 오디오북·비디오 진행률은 대상 DB에 같은 ID의 사용자가 있을 때 복원합니다. 다른 사람의 같은 ID로 연결되지 않는지 확인하세요.
  • 실제 가져오기 전 외부 백업을 만들고 BookOasis의 스캔·메타데이터 변경을 멈춥니다. 자동 DB 백업은 작업 디렉터리의 backups에 저장합니다.
  • SQLite FTS5를 사용하는 DB는 FF SQLite에도 FTS5가 필요합니다. MariaDB 백업에는 mariadb-dump 또는 mysqldump가 필요합니다.
