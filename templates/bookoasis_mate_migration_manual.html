카테고리 이관 매뉴얼

BookOasis 공식 카테고리 패키지 형식 2.0을 사용해 일반·성인 도서와 오디오북·비디오 카테고리를 내보내거나 신규·기존 카테고리로 가져옵니다. 비디오 패키지는 비디오·에피소드·재생 진행률·포스터를 함께 처리합니다.

DB 엔진과 무관한 데이터 패키지이므로 같은 미디어 유형이면 SQLite에서 내보낸 카테고리를 MariaDB로 가져오거나 그 반대로 가져올 수 있습니다.
패키지 유형가져오기 대상포함 범위
일반일반도서·진행률·표지
성인성인도서·진행률·표지
오디오북오디오북오디오북·트랙·진행률·표지
비디오비디오비디오·에피소드·진행률·포스터

1. 공통 설정

  1. 설정 → 표지 디렉터리에 FlaskFarm에서 보이는 BookOasis covers 경로를 입력합니다.
  2. 복사 설정 → 이관 작업 디렉터리에 패키지와 백업 파일을 저장할 경로를 입력합니다.
  3. 패키지에 저장할 대상 물리 경로는 BookOasis가 실제로 사용하는 경로여야 합니다. FF가 파일 검사·복사를 수행하는 작업은 FF에서도 해당 경로에 접근할 수 있어야 합니다.

2. 내보내기

  1. 작업 유형에서 내보내기를 선택합니다.
  2. 일반·성인·오디오북·비디오 DB와 하나 이상의 카테고리를 선택하고 설정을 저장합니다.
  3. 복사 상태에서 시작을 누릅니다.
  4. 완료된 .oasis.zip 파일은 이관 작업 디렉터리에 생성됩니다.

3. 신규 카테고리로 가져오기

  1. 이관 작업 디렉터리에 .oasis.zip 패키지를 복사합니다.
  2. 작업 유형에서 가져오기를 선택하고 패키지 검사를 실행합니다.
  3. 새 대상 경로를 개수 제한 없이 한 줄에 하나씩 입력합니다.
  4. 설정을 저장하고 복사 상태에서 시작을 누릅니다.

대상 경로는 원본 경로 순서대로 대응합니다. 대상 경로가 부족하면 남은 도서·오디오북·비디오는 첫 번째 대상 경로로 가져옵니다.

가상 그룹은 설치 환경별 관리 정보이므로 패키지에 포함하지 않습니다. 가져오기 후 가상 그룹은 BookOasis에서 다시 지정합니다.

가져오기 전에 ZIP CRC와 DB 무결성을 검사합니다. DB 백업을 켜면 backups 폴더에 SQLite 백업 또는 MariaDB 논리 백업을 생성합니다.

4. 기존 카테고리에 병합

  1. 가져오기 방식에서 기존 카테고리 병합을 선택합니다.
  2. 일반·성인·오디오북·비디오 DB를 선택한 뒤 병합 대상 카테고리를 선택합니다.
  3. 추가할 물리 경로를 한 줄에 하나씩 입력하고 설정을 저장합니다.
  4. 복사 상태에서 시작을 누릅니다.

대상 카테고리의 기존 물리 경로는 유지되며 새 경로만 추가합니다. 도서는 최종 파일 경로, 오디오북·비디오는 폴더 경로와 하위 미디어 파일 경로가 이미 있으면 중복으로 판단해 건너뜁니다.

주의 사항

  • 병합 대상은 공식 --merge-to와 같이 카테고리 ID로 지정합니다.
  • SQLite DB가 FTS5를 사용하면 FF Python의 SQLite도 FTS5를 지원해야 하며, 가져오기 전에 자동 검사합니다.
  • MariaDB 백업에는 FF 컨테이너에서 실행 가능한 mariadb-dump 또는 mysqldump가 필요합니다.
  • 실행 중인 가져오기 작업을 중지하면 DB 트랜잭션과 임시 표지를 정리합니다.
  • 가져오기 중에는 BookOasis 스캔과 메타데이터 변경 작업을 피하는 것이 안전합니다.
  • 도서·오디오북·비디오 패키지는 같은 미디어 유형의 DB로만 가져올 수 있습니다.
  • 오디오북 재생 진행률은 대상 오디오북 DB에 같은 ID의 사용자가 있을 때만 복원합니다.
  • 비디오 재생 진행률은 대상 비디오 DB에 같은 ID의 사용자가 있을 때만 복원합니다.
