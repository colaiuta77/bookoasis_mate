메뉴사용 방법결과 해석
상태 요약캐시를 먼저 표시하고 필요 시 갱신. 검사 실행 및 기록으로 최신 결과 저장.문제 수는 DB 값 기준이며 실제 파일 손상을 뜻하지 않습니다.
라이브러리 통계DB·보관함 선택 후 분석.용량·형식·등록 추이·이용 현황. 실제 디스크 사용량과 다를 수 있습니다.
스캔 상태보관함·최근 작업과 실시간 상태 확인. 필요할 때만 재스캔.DB 이력과 관리자 API 상태를 구분합니다. 자동 갱신은 2초 주기입니다.
문제 도서문제 유형·보관함 필터 → JSON으로 값 확인.상세 보기·개별 재스캔·플러그인 메타데이터 검색은 별도 실행입니다.
시리즈 누락분석 후 후보 확인, 필요 시 CSV 저장.권·화·Vol 등 제목·파일명에서 추정합니다. 특수권·불규칙한 이름은 오탐이 가능합니다.
검사 이력저장된 검사 결과 조회·삭제.이력 삭제는 BookOasis 도서를 삭제하지 않습니다.
BookOasis 로그파일·오류 수준·검색어 선택.화면 지우기는 로그 파일 삭제가 아닙니다. Mate 자체 오류는 최상단 로그 메뉴에서 확인합니다.

상태 요약·통계·표지 정밀 검사는 별도 프로세스에서 수행합니다. 메뉴를 이동해도 작업이 계속될 수 있으므로 진행 상태를 확인하세요.

DB 무결성 검사는 SQLite에 PRAGMA quick_check, MariaDB에 CHECK TABLE ... QUICK을 실행합니다. 정상 결과가 미디어 파일의 정상까지 보장하지는 않습니다.

점검 필요 판정

  • 메타데이터 — 표지·저자·출판사·소개 등 누락. ISBN 검사는 설정에 따라 적용합니다. 중복 ISBN은 중복 파일 확정이 아닌 후보입니다.
  • 페이지 수 미기록 — books.total_pages가 없거나 0 이하.
  • 파일 크기 미기록 — books.file_size가 없거나 0 이하. 크기의 이상치를 찾는 검사는 아닙니다.
  • 원격 페이지 분석 제한 — 원격 ZIP·CBZ의 페이지·표지 미기록은 상태 요약에서 별도 참고값으로 분리합니다.
  • 오디오북 점검 필요 — 포스터·저자·출판사·소개 누락 또는 트랙 수 0 이하.
  • 비디오 점검 필요 — 포스터·소개·장르 누락 또는 에피소드 수·재생 시간 0 이하.

한 항목이 여러 조건에 해당해도 점검 필요 총계에는 중복 집계하지 않습니다. 오디오북·비디오의 하위 파일 정보 미기록은 별도 참고값입니다.

미기록 값이 있으면 먼저 경로 접근과 BookOasis 스캔 로그를 확인하세요. 페이지 계산·보정 방식은 파일 형식과 BookOasis 버전에 따라 다르며, Lazy Scanner만으로 모든 누락이 해소되지는 않습니다.

표지 검사·고아 표지파일 정리

  1. 공통 설정에서 표지 경로와 원격 커버 경로 확인값을 점검합니다.
  2. 표지 검사에서 DB·보관함·검사 유형을 선택합니다. 표지 없음은 DB 참조를, 저해상도·작은 파일·비정상 비율은 실제 파일을 검사합니다.
  3. 같은 조건의 정밀 검사 결과는 재사용됩니다. 실제 표지가 바뀌었다면 새 검사를 실행합니다.
  4. 고아 표지파일 정리는 Dry Run으로 대상·용량을 확인한 뒤 백업합니다. 실제 삭제는 Dry Run을 끄고 확인한 경우에만 실행합니다.

DB·표지 경로가 잘못되면 정상 파일을 고아로 판단할 수 있습니다. 커버 이동·스캔·메타데이터 변경 중에는 삭제하지 마세요.
