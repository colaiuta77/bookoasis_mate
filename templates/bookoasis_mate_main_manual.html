라이브러리 상태와 도서 진단

라이브러리 통계
  • 설명 — DB와 보관함별 도서·오디오북·비디오 수, 저장 용량, 파일 형식, 메타데이터 완성도, 등록 추이와 독서·청취·시청 상태를 Chart.js 차트로 보여줍니다.
  • 동작 방식 — 페이지 진입 시 자동 실행하지 않습니다. 분석 버튼을 누르면 FF 웹 요청과 분리된 별도 프로세스에서 읽기 전용으로 계산하며, 메뉴를 이동했다 돌아와도 진행 상태와 마지막 결과를 복원합니다.
  • 장르와 태그는 쉼표·세미콜론·파이프로 구분해 대소문자를 합산합니다. 파일 용량과 포맷은 BookOasis DB에 기록된 값을 기준으로 하므로 미기록 파일은 실제 디스크 사용량과 차이가 날 수 있습니다.
상태 요약
  • 설명 — 일반·성인 활성 도서의 정상·점검 필요 비율과 메타데이터·페이지 수·파일 크기 미기록, 오디오북·비디오와 최근 스캔 상태를 한 화면에 집계합니다.
  • 동작 방식 — BookOasis DB를 읽기 전용으로 조회합니다. 화면 진입 시 캐시가 있으면 먼저 표시하고 오래되었거나 없으면 FF 웹 요청과 분리된 별도 프로세스에서 갱신합니다. 검사 실행 및 기록을 누르면 최신 값을 다시 계산해 검사 이력에 저장합니다. 수동 DB 무결성 검사는 SQLite에 PRAGMA quick_check, MariaDB에 CHECK TABLE ... QUICK을 실행합니다.
  • 오디오북 점검 필요 — 활성 오디오북 중 포스터·저자·출판사·소개가 비었거나 트랙 수가 0 이하인 항목을 중복 없이 집계합니다. 트랙 파일 크기 미기록은 별도 참고값이며 점검 필요 수에는 포함하지 않습니다.
  • 비디오 점검 필요 — 활성 비디오 중 포스터·소개·장르가 비었거나 전체 에피소드 수·재생 시간이 0 이하인 항목을 중복 없이 집계합니다. 에피소드 파일 크기·길이·해상도 미기록과 컨테이너 확인 필요 값은 별도 참고값입니다.
문제 도서
  • 설명 — 저자·출판사·소개·ISBN 누락, 페이지 수·파일 크기 미기록과 중복 ISBN 후보를 보관함 및 문제 유형별로 찾습니다.
  • 동작 방식 — 저장된 DB 값을 조건별로 조회하며 파일은 수정하지 않습니다. 행의 JSON 버튼에서 적용된 규칙과 실제 값을 확인할 수 있고, 행 메뉴에서 상세 보기·개별 재스캔·플러그인 메타데이터 검색을 별도로 실행할 수 있습니다.
스캔 상태
  • 설명 — 보관함 상태, 최근 스캔 작업과 현재 실행 중인 BookOasis·Lazy Scanner 작업을 함께 보여줍니다.
  • 동작 방식 — DB 작업 이력과 BookOasis 관리자 API의 실시간 상태를 결합해 표시하며 자동 갱신을 켜면 2초마다 새로 조회합니다. exit_pending은 메모리 환수 후 자동 재개되는 실행 흐름으로 집계하고, 체크포인트는 중단 후 이어서 처리할 수 있도록 저장된 완료 폴더 수입니다.
  • 원격 보관함은 VFS 사전 갱신 설정과 RC 주소 설정 여부만 표시하며 주소나 인증정보 자체는 화면에 전달하지 않습니다. 보관함별 또는 전체 재스캔은 사용자가 버튼을 눌렀을 때 BookOasis API에 요청합니다.

시리즈와 표지 진단

시리즈 누락
  • 설명 — 같은 시리즈의 보유 권차 사이에서 비어 있는 번호를 찾아 예상 누락 후보로 보여줍니다.
  • 동작 방식 — 분석 버튼을 누르면 DB 제목과 원본 파일 경로의 E0001, [01], 권·화·편·Vol 및 범위 표기를 해석합니다. 특수권이나 불규칙한 파일명은 오탐이 될 수 있으므로 원본을 확인해야 하며, 현재 조건의 전체 후보는 CSV로 내보낼 수 있습니다.
표지 검사
  • 설명 — DB 표지 없음, 저해상도, 지나치게 작은 파일 크기와 비정상 비율에 해당하는 표지만 표시합니다.
  • 동작 방식 — 표지 없음은 DB 참조를 즉시 확인합니다. 저해상도·파일 크기·비율 검사는 별도 프로세스에서 실제 표지 파일을 한 번만 읽어 세 기준을 함께 분석하며 정상 표지는 결과에서 제외합니다.
  • 백그라운드 작업 — 정밀 검사는 다른 메뉴로 이동해도 계속 실행됩니다. 표지 검사로 돌아오면 진행률과 결과를 복원하며, 같은 DB·보관함·검색 조건에서는 검사 유형을 바꿔도 저장된 공통 분석 결과를 재사용합니다.
고아 표지파일 정리
  • 설명 — 표지 디렉터리에는 남아 있지만 BookOasis DB에서 참조하지 않는 표지 파일을 찾아 정리합니다.
  • 동작 방식 — 선택한 범위의 DB 참조와 실제 표지 파일을 대조합니다. 기본값인 Dry Run은 삭제 없이 대상과 용량만 보여주며, 실제 삭제는 Dry Run을 끄고 확인한 경우에만 백그라운드에서 진행됩니다.

진단 결과를 먼저 확인하고 원본 DB와 표지를 백업한 뒤 삭제 작업을 실행하는 것을 권장합니다.

페이지 수·파일 크기 판정 기준

  • 페이지 수 미기록은 books.total_pages가 0 이하이거나 값이 없는 도서입니다. 단, BookOasis가 내부 분석을 의도적으로 생략하는 원격 ZIP·CBZ는 점검 필요에서 제외하고 원격 페이지 분석 제한으로 별도 집계합니다.
  • 파일 크기 미기록은 books.file_size가 0 이하이거나 값이 없는 도서입니다.
  • 두 항목은 값이 너무 크거나 작은지를 판정하는 이상치 검사가 아니라, 아직 값이 기록되지 않은 도서를 찾는 검사입니다.

BookOasis 저장·갱신 시점

  • 전체 스캔은 실제 파일의 수정 시각과 크기를 읽어 신규·기존 도서에 저장합니다. 이미지 폴더는 내부 이미지 파일 크기의 합계를 저장합니다.
  • ZIP·CBZ는 이미지 오프셋을 만들 때 이미지 엔트리 수를 total_pages에 저장합니다.
  • 페이지 수가 0인 ZIP·CBZ·PDF·이미지 폴더는 상세 정보 또는 뷰어 요청 과정에서 페이지 수를 다시 계산해 DB에 저장할 수 있습니다.
  • EPUB은 신규 스캔 시 호환용 페이지 수 100을 저장합니다. TXT는 페이지 수 계산 경로가 없어 0이 유지될 수 있습니다.
  • Lazy Scanner는 ZIP·CBZ 오프셋 생성 시 페이지 수를 갱신하지만 books.file_size는 갱신하지 않습니다.
  • 원격 ZIP·CBZ는 네트워크 부하 방지를 위해 전체 스캔에서 내부 오프셋과 아카이브 첫 페이지 표지 추출을 생략할 수 있습니다. 이때 페이지·표지 미기록은 상태 요약에서 원격 분석 제한으로 분리됩니다.
  • 메타데이터 잠금은 표지·제목·저자 같은 메타데이터 갱신을 제한합니다. 파일 크기와 오프셋 기반 페이지 수 저장에는 적용되지 않습니다.

0으로 남을 수 있는 경우와 권장 조치

  • FlaskFarm 또는 BookOasis에서 원격 파일 경로에 접근할 수 없으면 파일 크기 조회가 실패해 0이 남을 수 있습니다.
  • 파일 크기 미기록 도서는 Lazy Scanner만으로 해소되지 않으므로 경로 접근 상태를 확인한 뒤 해당 보관함의 전체 스캔을 실행합니다.
  • 페이지 수 미기록은 지원 형식의 상세 보기·뷰어 접근으로 보정될 수 있지만, 많은 도서를 일괄 보정하려면 전체 스캔과 Lazy Scanner 상태를 함께 확인합니다.
  • TXT의 페이지 수 0은 현재 저장 로직상 정상일 수 있으므로 파일 형식을 함께 확인합니다.
