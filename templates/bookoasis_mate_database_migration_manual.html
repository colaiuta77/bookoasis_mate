통DB 이관 매뉴얼

Kavita 도서·메타데이터·표지와 진행률을 BookOasis에 새로 생성하거나 기존 항목에 적용하고, BookOasis 전체 DB와 표지를 공유 패키지로 내보내고 가져옵니다.

1. Kavita → BookOasis
  1. 이관 원본을 Kavita로 선택하고 kavita.db와 필요한 경우 표지 디렉터리를 지정합니다.
  2. DB 검사·자동 설정으로 이관할 보관함, 경로 매핑과 사용자 매핑을 확인한 뒤 미리보기를 실행합니다.
  3. 미리보기에서 신규 생성·기존 갱신·경로 미일치 도서 수를 확인합니다.
  4. Dry Run 결과를 확인한 뒤 BookOasis 읽기·스캔 작업을 중지하고 실제 이관합니다.

대상은 BookOasis 일반 또는 성인 DB이며 SQLite와 MariaDB를 모두 지원합니다. 선택한 Kavita 보관함과 도서는 새로 생성하거나 기존 항목을 갱신합니다. 사용자 계정 자체는 만들지 않으며, 진행률은 매핑한 기존 BookOasis 사용자에게만 적용합니다.

2. BookOasis 패키지 내보내기
  1. 이관 원본을 BookOasis 패키지로 선택하고 작업 유형에서 내보내기를 선택합니다.
  2. 패키지 이름과 이관 작업 디렉터리를 저장한 뒤 이관 상태에서 시작합니다.
  3. 완료된 db_이름_날짜.tar.gz와 covers_이름_날짜.tar.gz를 한 세트로 보관하거나 공유합니다.

SQLite 모드는 존재하는 일반·성인 DB와 선택적 오디오북 DB를 파일 패키지로 저장합니다. MariaDB 모드는 일반·성인·오디오북 3개 DB의 SQL 논리 백업을 생성합니다.

3. BookOasis 패키지 가져오기
  1. 공유받은 DB·표지 패키지를 이관 작업 디렉터리에 그대로 복사합니다. 압축을 직접 해제하지 않습니다.
  2. DB 패키지와 표지 패키지를 각각 선택하고 DB 패키지 검사로 무결성, 보관함, 도서 수와 원본 물리 경로를 확인합니다.
  3. 원본과 현재 서버의 /GDRIVE 상위 경로가 다르면 상위 경로만 매핑합니다.
  4. Dry Run으로 압축 검사, 경로 변환, 표지 참조와 최종 DB 무결성을 확인합니다.
  5. BookOasis와 모든 스캐너를 중지한 뒤 이관 상태에서 실제 가져오기를 시작합니다.

대용량 작업은 FlaskFarm 웹 요청과 분리된 작업 프로세스에서 실행되며 이관 상태에서 진행률을 확인할 수 있습니다.

4. MariaDB 도구 설치

PyMySQL은 FF가 MariaDB에 직접 연결할 때 사용하는 Python 드라이버입니다. 실행 중인 FF 컨테이너와 같은 Python에 설치하고 플러그인을 다시 로드합니다.

docker exec -u 0 flaskfarm python -m pip install --no-cache-dir "PyMySQL>=1.1"
docker exec flaskfarm python -c "import pymysql; print(pymysql.__version__)"

mariadb-client는 통DB 논리 패키지의 내보내기·가져오기에 필요한 mariadb와 mariadb-dump 명령을 제공합니다. Debian·Ubuntu 계열 FF 이미지에서는 다음과 같이 설치합니다.

docker exec -u 0 flaskfarm sh -lc 'apt-get update && apt-get install -y --no-install-recommends mariadb-client && rm -rf /var/lib/apt/lists/*'
docker exec flaskfarm sh -lc 'mariadb --version && mariadb-dump --version'

컨테이너 이름이 다르면 flaskfarm을 실제 이름으로 바꿉니다. 배포판은 docker exec flaskfarm cat /etc/os-release로 확인할 수 있으며 Alpine 계열은 apk add --no-cache mariadb-client를 사용합니다.

컨테이너에 직접 설치한 패키지는 단순 재시작에는 남지만 이미지 업데이트나 컨테이너 재생성 시 사라집니다. 계속 사용할 환경은 현재 FF 이미지 태그에 맞춘 사용자 이미지를 권장합니다.

# Dockerfile.ff-mariadb
FROM flaskfarm/flaskfarm:4.1
USER root
RUN apt-get update \
    && apt-get install -y --no-install-recommends mariadb-client \
    && python -m pip install --no-cache-dir "PyMySQL>=1.1" \
    && rm -rf /var/lib/apt/lists/*

PyMySQL만 설치하면 진단·조회 기능은 사용할 수 있지만 통DB MariaDB 내보내기·가져오기는 실행할 수 없습니다. 통DB 기능에는 mariadb-client도 필요합니다.

주의 사항

  • 첫 실행은 반드시 Dry Run으로 수행하고 결과의 일치·미일치 수와 오류를 확인합니다.
  • 실제 적용 전 현재 일반·성인·오디오북 DB와 표지 디렉터리를 별도로 백업합니다. 플러그인 백업과 별개로 외부 백업도 유지하는 것을 권장합니다.
  • 실제 이관 중에는 BookOasis, 스캐너와 메타데이터 변경 작업을 중지해야 합니다.
  • BookOasis 패키지 가져오기는 패키지에 포함된 일반·성인·오디오북 DB와 전체 표지를 교체하며 기존 데이터와 병합하지 않습니다.
  • 공유 DB의 사용자 계정과 독서 진행률도 함께 바뀌므로 출처와 BookOasis 스키마 버전을 신뢰할 수 있는 패키지만 사용합니다.
  • SQLite DB 패키지는 db/media_*.db, MariaDB 패키지는 검증용 manifest와 db/media_*.sql 구조이며 표지 패키지는 covers/ 트리여야 합니다.
  • MariaDB 내보내기·가져오기에는 FF 컨테이너에 PyMySQL과 mariadb-dump·mariadb 또는 호환 mysql 클라이언트가 필요합니다.
  • 통DB 패키지는 생성 엔진과 같은 엔진에만 복원할 수 있습니다. SQLite와 MariaDB 사이의 변환 도구로 사용하지 않습니다.
  • 경로 매핑은 보관함과 도서 경로, 표준 book_해시.webp 참조·파일명에 적용됩니다. 사용자 지정 표지와 series_ 표지는 이름을 바꾸지 않습니다.
  • 압축 경로 이탈, 심볼릭 링크, 필수 DB 누락, DB 무결성 검사 실패나 도서·오디오북 경로 충돌이 발견되면 실제 적용이 차단됩니다.
