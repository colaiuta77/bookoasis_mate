통DB 이관 매뉴얼

지원 범위

작업대상·동작
Kavita → BookOasis일반·성인 DB에 신규 생성 또는 기존 항목 갱신. SQLite·MariaDB 지원.
BookOasis 내보내기DB·표지를 한 세트로 백업.
BookOasis 가져오기같은 DB 엔진에 전체 교체. 기존 데이터와 병합하지 않습니다.

통DB 패키지에는 사용자 계정·진행률도 포함됩니다. 실제 가져오기 전에 DB·표지를 외부에 백업하고 BookOasis와 모든 스캐너를 중지하세요. 미디어 원본 파일은 별도입니다.

Kavita → BookOasis

  1. 이관 설정에서 Kavita를 선택하고 kavita.db·표지 경로·대상 DB를 지정합니다.
  2. DB 검사·자동 설정으로 보관함·경로·사용자 매핑을 확인합니다.
  3. 미리보기와 Dry Run으로 신규 생성·기존 갱신·경로 미일치 도서 수를 확인합니다.
  4. 백업과 쓰기 작업 중지를 확인한 뒤 Dry Run을 끄고 이관 상태 → 시작을 누릅니다.

사용자 계정 자체는 만들지 않으며, 진행률은 매핑한 기존 BookOasis 사용자에게 적용합니다.

BookOasis 패키지

내보내기. BookOasis 패키지 → 내보내기에서 이름·작업 디렉터리를 저장한 뒤 시작합니다. db_이름_날짜.tar.gz와 covers_이름_날짜.tar.gz를 함께 보관합니다.

SQLite는 존재하는 일반·성인·오디오북·비디오 DB를, MariaDB는 4개 DB의 논리 백업을 포함합니다.

  1. 가져오기를 선택하고 DB·표지 패키지를 각각 지정합니다. 압축을 직접 해제하지 않습니다.
  2. DB 패키지 검사로 DB 엔진·보관함·원본 경로를 확인합니다.
  3. 달라진 경로만 /원본/미디어 => /현재/미디어로 매핑합니다.
  4. Dry Run으로 임시 DB·표지에서 압축·경로 변환·무결성 검사를 마칩니다.
  5. BookOasis·스캐너를 중지하고 백업을 확인합니다. Dry Run을 끄고 상태 화면에서 중지 확인 후 실행합니다.

상태 API가 healthy로 응답하면 실제 복원을 차단합니다. 접속 불가만으로 서버 중지가 증명되는 것은 아니므로 직접 확인해야 합니다.

주의 사항

  • 자동 백업은 존재하는 대상 DB만 백업합니다. 신규 설치의 없는 DB는 건너뜁니다. MariaDB 실제 복원은 DB 백업을 켜야 합니다.
  • SQLite와 MariaDB 통DB 패키지는 교차 복원할 수 없습니다. 일부 데이터만 옮기려면 카테고리 이관을 사용하세요.
  • 경로 이탈·심볼릭 링크·필수 DB 누락·무결성 실패·경로 충돌은 적용을 차단합니다. 임시 압축 해제와 백업을 위한 여유 공간도 확보하세요.
  • 경로 매핑은 DB 경로와 표준 book_해시.webp에 적용합니다. 사용자 지정 표지·series_ 표지의 이름은 바꾸지 않습니다.
  • 출처와 스키마 버전이 맞는 패키지만 사용하세요. 실행 중에는 경로나 원본 파일을 바꾸지 마세요.
  • MariaDB 도구는 설정 → DB 연결 → MariaDB 필수 구성요소에서 확인합니다.
