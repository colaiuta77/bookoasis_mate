로컬 폴더 감지

로컬 디스크는 실시간 이벤트로, Windows Docker·CIFS/NFS·FUSE는 폴링으로 변경을 확인합니다. 매뉴얼

감시 설정

두 경로 모두 각 컨테이너에서 보이는 절대 경로입니다. 설정 변경은 작업 중지 후 적용하세요.

BookOasis 연결 및 Discord 웹훅은 기존 Mate 설정을 사용합니다. Google Drive 연동을 켤 필요는 없습니다.

변경 이벤트

ID·수신변경경로상태작업

사용 매뉴얼

  1. 감시 폴더를 FlaskFarm 컨테이너에 마운트하고, 동일 자료를 BookOasis 보관함에도 연결합니다.
  2. Mate 경로와 BookOasis 경로를 입력합니다. 예를 들어 /watch/books → /data/books입니다.
  3. Linux 실제 디스크는 자동 또는 실시간, Windows Docker·SMB/CIFS·NFS·FUSE는 폴링을 선택합니다.
  4. 저장 후 시작합니다. 최초 조회는 기준만 만들며 기존 파일을 스캔하지 않습니다.
  • 실시간 감지에는 FlaskFarm Python 환경의 watchdog>=4,<7 설치가 필요합니다. 없으면 오류를 표시하며 자동 설치하지 않습니다.
  • 실시간 모드는 watchdog 신호를 모아 변경 시 트리를 비교합니다. 폴링은 매 주기 파일 크기·수정시간을 비교합니다. 대규모 경로는 조회 비용이 크며 루트당 최대 20만 항목입니다.
  • 이동은 삭제+생성으로 기록합니다. 심볼릭 링크는 따라가지 않습니다. 감시 중지·재시작 사이의 변경은 자동 복구하지 않습니다.
  • 루트 변경·조회 오류·빈 트리·대량 삭제는 기준을 유지하고 보류합니다. 정상 삭제임을 확인했다면 BookOasis 수동 스캔 후 중지·시작으로 새 기준을 만드세요.
  • 같은 경로의 네이티브 플러그인·gd-poller 감시는 직접 꺼 주세요. Mate 내 Drive 자체 감지와 겹치는 대상은 시작할 수 없습니다.
  • 로컬 스캔은 rclone VFS를 갱신하지 않습니다. FUSE 캐시에 아직 보이지 않는 변경은 감지할 수 없습니다.
  • 중지 시 감지는 종료하고 현재 API 요청 이후 스캔을 멈춥니다. 대기열은 유지되며 별도로 삭제할 수 있습니다. 처리 이력은 30일 보관합니다.
  • 요청 완료는 BookOasis가 스캔 요청을 수락했다는 뜻입니다. 최종 스캔 완료 여부는 BookOasis에서 확인하세요.
  • Windows 네이티브 FlaskFarm 실행은 지원 범위 밖입니다. Windows PC 공유 폴더는 NAS/컨테이너에 CIFS로 마운트해야 합니다.
