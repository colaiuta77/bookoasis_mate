BookOasis Mate 매뉴얼

모든 기능에 공통으로 적용되는 연결 조건, 필수 패키지, 파일 권한과 안전 수칙을 안내합니다. 기능별 세부 절차는 각 메뉴의 매뉴얼을 확인하세요.

  • 사용 안내
  • 변경 내역

1. 공통 연결 조건

  • FF에서 BookOasis URL에 접근할 수 있어야 하며 관리자 API 기능에는 BookOasis 관리자 계정이 필요합니다.
  • 보관함 스캔 웹훅은 BookOasis .env의 WEBHOOK_TOKEN과 같은 값을 사용합니다.
  • SQLite 진단·이관은 FF 컨테이너에서 BookOasis DB 파일을 볼 수 있어야 합니다. 표지 검사·정리, 로그와 커스텀 폰트도 해당 호스트 경로를 FF에 마운트해야 합니다.
  • MariaDB 진단·이관은 FF에서 MariaDB 호스트에 접속할 수 있어야 합니다. 진단은 읽기 권한, 실제 이관은 대상 DB 쓰기와 논리 백업·복원 권한이 필요합니다.
  • 경로 입력값은 호스트 경로가 아니라 FF 컨테이너에서 보이는 경로를 기준으로 합니다.

2. MariaDB 필수 패키지

PyMySQL 1.1 이상 2.0 미만은 FlaskFarm이 MariaDB에 직접 연결할 때 사용하는 Python 드라이버입니다.

mariadb-client는 MariaDB 통DB·카테고리·Kavita 이관의 논리 백업과 복원에 사용하는 mariadb와 mariadb-dump 명령을 제공합니다.

설치 상태 확인, 설치·재설치와 필요한 패키지 자동 설치는 설정 → DB 연결 → MariaDB 필수 구성요소에서 진행합니다.

3. 컨테이너 재생성 후에도 유지하기

실행 중인 컨테이너에 직접 설치한 패키지는 단순 재시작에는 남지만 이미지 업데이트나 컨테이너 재생성 시 사라집니다. 계속 사용할 환경은 사용자 이미지를 권장합니다.

Dockerfile
# Dockerfile.ff-bookoasis-mate
FROM flaskfarm/flaskfarm:4.1
USER root
RUN apt-get update \
    && apt-get install -y --no-install-recommends mariadb-client \
    && python -m pip install --no-cache-dir "PyMySQL>=1.1" \
    && rm -rf /var/lib/apt/lists/*

PyMySQL만 설치하면 MariaDB 진단·조회는 가능하지만 논리 백업·복원 기능은 실행할 수 없습니다.

4. 안전 수칙

  • 카테고리·Kavita·통DB 실제 이관 전에는 Dry Run과 별도 외부 백업을 완료합니다.
  • DB를 변경하거나 교체하는 동안 BookOasis, 스캐너와 메타데이터 변경 작업을 중지합니다.
  • API 키, 관리자 비밀번호와 MariaDB 비밀번호는 로그·스크린샷·공유 설정 파일에 포함하지 않습니다.
  • 고아 표지 정리는 Dry Run 결과를 먼저 확인하고, 삭제 범위와 백업 위치를 검토한 후 실행합니다.
  • SQLite와 MariaDB 통DB 패키지는 서로 교차 복원하지 않습니다.

5. BookOasis 공식 구현 참고

  • database.py — 일반·성인·오디오북·비디오 DB 역할과 공통 스키마.
  • api_endpoints.md — 상태 조회, 스캔, 도서 작업과 상세 화면 연동 API 계약.
  • move_to_mariadb.md — SQLite·MariaDB 엔진 설정과 공식 전환 절차.
  • scanner/tasks.py와 scanner/db_writer.py — 전체 스캔의 파일 정보 수집과 DB 저장.
  • book_info_service.py와 lazy_scanner.py — 상세·뷰어 요청과 지연 스캔의 정보 보정.
  • SQLite 오디오북 저장소와 MariaDB 오디오북 저장소 — 오디오북·트랙·재생 진행률의 엔진별 구현.
  • SQLite 비디오 저장소와 MariaDB 비디오 저장소 — 작품·에피소드·시청 진행률의 엔진별 구현.
  • spec_scanner_logic.md — 체크포인트, 원격 경로, VFS와 예외 필터를 포함한 스캐너 명세.
  • export_category.py, import_category.py와 guide_category_migration.md — 카테고리 패키지 형식과 병합 계약.

6. 오디오북 공통 지원

  • SQLite의 db/media_audiobook.db 또는 MariaDB의 오디오북 DB를 별도로 연결하며 상태 요약, DB 무결성 검사, DB 정보·보관함 확인, 스캔 상태와 읽기 전용 SQL에서 사용할 수 있습니다.
  • Google Drive 변경 연동은 MP3·M4B·M4A·FLAC·AAC·WAV·OGG·OPUS·WMA 이벤트를 오디오북 보관함에 연결해 VFS 갱신과 보관함 스캔을 요청할 수 있습니다.
  • 오디오북은 audiobooks·audiobook_tracks 구조를 사용하므로 도서 전용 문제 도서, 시리즈 누락, 표지 검사, 개별 도서 재스캔과 메타데이터 적용 메뉴에는 표시하지 않습니다.

7. 비디오북 공통 지원

  • SQLite의 db/media_video.db 또는 MariaDB의 비디오 DB를 별도로 연결하며 상태 요약, 라이브러리 통계, DB 정보·보관함 확인, 스캔 상태와 읽기 전용 SQL에서 사용할 수 있습니다.
  • Google Drive 변경 연동은 MP4·MKV·AVI·WEBM·MOV·M4V·TS와 SMI·SRT·VTT 이벤트를 비디오 보관함의 개별 경로 스캔으로 연결합니다.
  • 비디오는 videos·video_episodes 구조를 사용하므로 도서 전용 문제 도서, 시리즈 누락, 표지 검사와 도서 메타데이터 메뉴에는 표시하지 않습니다.

8. 네이티브 플러그인 관리

  • 카탈로그는 Mate에서 확인한 저장소와 사용자가 등록한 저장소를 관리하며, 실제 설치 전에 ZIP 구조와 Python 패키지를 검사합니다.
  • 실행 상태는 최신 BookOasis 관리 API에서 설치 발견 여부, 활성화 여부와 실제 로드 성공·오류를 구분해 표시합니다.
  • 플러그인이 config_schema를 제공하면 Mate에서 설정할 수 있습니다. 비밀번호·토큰 값은 브라우저에 반환하지 않으며 비워 두면 기존 값을 유지합니다.
  • 네이티브 업데이트 계약을 지원하는 플러그인은 BookOasis 업데이트 API를 사용합니다. GitHub 직접 설치·업데이트와는 별도 기능입니다.
  • Topic 탐색은 GitHub의 bookoasis-plugin Topic 후보를 백그라운드에서 수집하고 캐시합니다. 후보는 자동 설치하지 않으며 VERSION과 플러그인 ID 확인 후 기존 패키지 검사로 넘깁니다.

9. 기능별 안내 위치

라이브러리 진단판정 기준, 스캔 상태, 표지·고아 파일 동작 방식.
카테고리 이관내보내기, 신규 가져오기, 기존 카테고리 병합.
통DB 이관Kavita 이관과 BookOasis 전체 패키지 내보내기·가져오기.
Google Drive 연동gd-poller 래퍼, 경로 매핑, VFS 갱신과 스캔 큐.
커스텀 폰트공유 마운트 경로, 파일 업로드와 BookOasis 재시작 조건.
