gd-poller 연동

CommandDispatcher는 기존 래퍼를 실행하고 WebhookDispatcher는 아래 이벤트 API로 JSON을 직접 전송합니다. 두 방식 모두 동일한 Mate 대기열과 스캔 로직을 사용합니다.

Mate 자체 변경 감지

Mate 전용 rclone 실행 파일과 rclone.conf를 사용합니다. 직접 Drive 또는 Union 안의 실제 Drive upstream을 감시하며 Google Drive Changes API 체크포인트와 파일 경로 상태는 Mate DB에 저장합니다.

경로 매핑 검사

gd-poller가 래퍼에 전달할 경로를 입력하면 현재 입력된 Mate 매핑과 VFS 규칙으로 변환 결과를 검사합니다. 설정을 저장하기 전에도 사용할 수 있습니다.

한 줄에 로컬경로|리모트경로|RC주소#VFS이름|사용자|비밀번호를 입력합니다. 인증이 없으면 마지막 두 필드를 생략합니다.

Discord 변경 요약 알림

Mate 작업자가 버퍼 단위 처리를 마친 뒤 변경 수량·처리 결과·대상 보관함·실제 스캔 방식을 한 번만 요약해 전송합니다. 전송 실패는 Google Drive 스캔 결과에 영향을 주지 않습니다.
