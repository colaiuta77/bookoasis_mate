Google Drive 변경 감지 연동

gd-poller 이벤트를 먼저 FlaskFarm DB에 저장하고 버퍼 시간이 지난 뒤 rclone VFS 갱신과 BookOasis 개별 경로 스캔을 실행합니다. BookOasis v1.9.5 이상과 관리자 계정 설정이 필요합니다.

한 줄에 /gd-poller/경로 => /BookOasis DB의/보관함/경로를 입력합니다. 가장 긴 접두사가 우선하며 대상은 libraries.physical_path와 같은 논리 경로여야 합니다.

경로 매핑 검사

gd-poller가 래퍼에 전달할 경로를 입력하면 현재 입력된 Mate 매핑과 VFS 규칙으로 변환 결과를 검사합니다. 설정을 저장하기 전에도 사용할 수 있습니다.

한 줄에 로컬경로|리모트경로|RC주소#VFS이름|사용자|비밀번호를 입력합니다. 인증이 없으면 마지막 두 필드를 생략합니다.

이벤트 API

/bookoasis_mate/api/gdrive_scan/event

FlaskFarm 전역 API 키가 필요합니다. 개별 경로 스캔은 상단 설정 메뉴의 BookOasis 관리자 계정을 사용하며, 보관함 루트 폴백은 스캔 웹훅 토큰을 사용합니다.
