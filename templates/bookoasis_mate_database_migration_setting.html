일반·성인 DB는 안전한 백업과 롤백을 위해 한 번에 하나씩 실행합니다.

BookOasis 패키지 작업 유형

내보내기 설정

현재 일반·성인 DB와 전체 표지를 공유 가능한 두 개의 패키지로 저장합니다.

이관 작업 디렉터리에 `db_이름_날짜.tar.gz`와 `covers_이름_날짜.tar.gz`를 생성합니다. 일반·성인 DB는 SQLite backup API로 복사합니다.
DB와 표지의 시점을 정확히 맞추려면 스캐너와 메타데이터 변경 작업을 멈춘 상태에서 내보내세요.

가져오기 설정

공유받은 DB와 표지 패키지를 검사하고 현재 BookOasis 설치에 교체 적용합니다.

현재 일반·성인 DB와 전체 표지 디렉터리를 공유 패키지 세트로 교체합니다. 기존 DB와 병합하지 않으며 사용자·진행률도 공유 DB 내용으로 바뀝니다.
작업 디렉터리의 `db_*.tar.gz` 파일을 선택합니다. 패키지 검사는 DB 구조·무결성·원본 경로만 확인합니다.
작업 디렉터리의 `covers_*.tar.gz` 파일을 별도로 선택합니다. Dry Run 또는 실제 가져오기를 시작할 때 필요합니다.
`/books => /mnt/gds2`처럼 `/GDRIVE` 상위 폴더만 한 줄로 매핑하면 `/GDRIVE/READING/...` 하위 경로는 그대로 유지됩니다.
{{ macros.setting_checkbox('bookoasis_backup_before_import', '실행 전 DB 백업', value=arg.get('bookoasis_backup_before_import', 'True'), desc=['현재 일반·성인 DB를 SQLite backup API로 백업합니다.', '현재 표지 디렉터리는 같은 상위 경로에 별도 백업 디렉터리로 보존합니다.']) }} {{ macros.setting_checkbox('bookoasis_package_dry_run', 'BookOasis 패키지 Dry Run', value=arg.get('bookoasis_package_dry_run', 'True'), desc=['임시 DB와 임시 표지에서 압축 해제·경로 변경·무결성 검사를 끝까지 실행하되 현재 설치에는 적용하지 않습니다.']) }}
Dry Run을 끈 실제 가져오기는 상태 화면에서 매번 BookOasis 중지 여부를 확인해야 시작됩니다. 상태 API가 healthy로 응답하면 적용을 차단합니다.
