사용자 저장소 플러그인 추가

GitHub 또는 설정한 비공개 Gitea 저장소를 카탈로그에서 계속 관리합니다. 사용자 항목은 반드시 패키지 검사 후 설치합니다.

검증 분류를 선택해도 사용자 등록 저장소는 패키지 검사와 설치 확인을 거칩니다.

설치 정보와 BookOasis 실행 상태를 결합하고, 저장소가 확인되는 플러그인의 업데이트를 검사합니다.

저장소 패키지 검사

저장소를 임시 경로에 내려받아 구조·문법·파일 제한을 검사합니다. 검사 완료 후 별도 확인을 거쳐 설치합니다.

ZIP 패키지 업로드 검사

ZIP은 라이브 경로에 직접 해제하지 않으며 경로 이탈·심볼릭 링크·중첩 압축·비정상 압축률을 먼저 검사합니다.

최근 100개 검사·설치·실패 기록을 표시합니다.
