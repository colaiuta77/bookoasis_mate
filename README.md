# BookOasis Mate

**FF용 플러그인이며 BookOasis 서버가 실행되는 파일시스템에 접근할 수 있어야 합니다.**

## 주요 기능

- BookOasis 라이브러리 상태 요약과 문제 도서 진단.
- 스캔 상태 및 주요 로그 실시간 확인.
- 시리즈 누락, 표지 문제와 고아 표지파일 검사.
- 안전한 읽기 전용 SQL 진단 도구와 운영 프리셋.
- gd-poller 변경 감지 기반 rclone VFS 갱신과 BookOasis 증분 스캔.
- BookOasis 카테고리 내보내기·가져오기.
- Kavita 및 BookOasis 공유 패키지 통DB 이관.

## Changelog

- v1.1.0 (2026-08-03)
  - BookOasis 연동
    - 최신 관리자 API의 플러그인 상태·업데이트 정보와 개별 도서 작업 계약 반영.
    - 난독화된 도서 상세 주소 체계 지원과 상세 보기 호환성 개선.
    - 최신 스캐너 상태, 원격 도서 페이지 분석 제한과 gd-poller 변경 감지 기준 반영.
  - 라이브러리 진단
    - 일반·성인 DB를 안전하게 조회하는 읽기 전용 SQL 도구와 사용자·권한·진행률 진단 프리셋 추가.
    - 스캔 상태 표시와 장기 미스캔·원격 보관함 진단 기준 개선.
  - 도서 재스캔
    - 문제 도서와 표지 검사 결과의 백그라운드 일괄 재스캔 추가.
    - 일시적인 API 연결 중단을 항목별 재시도하고 화면별 작업 상태를 분리해 표시하도록 안정성 개선.
    - 결과 행 메뉴의 개별 도서 재스캔 복원과 일괄 작업 중 중복 실행 방지.
  - 표지 검사
    - 저해상도·작은 파일·비정상 비율 검사를 웹 요청과 분리된 백그라운드 작업으로 전환.
    - 한 번의 파일 분석 결과를 세 검사 유형이 공유하고 메뉴 재진입 시 진행률과 결과를 복원하도록 개선.
    - 표지 없음 검사는 빠른 DB 조회 방식을 유지하고 정밀 검사 결과를 일괄 재스캔과 연동.
